## The keystone idea

**Layer 0 defines what a stat is worth; everything else is priced against it.** A gacha rate, a promotion cost, an enemy's power budget, a ransom — all are meaningless until one stat point has a combat value. So the foundation was designed first and never re-litigated. Two consequences worth knowing before reading:

- **Combat Power (CP)** — one derived number (Layer 0 §4.1) is reused everywhere: the content generator's difficulty budget (Layer 2), PvP matchmaking (Layer 4), and all UI. Define power once, reference it forever.
- **Three permadeath sources, total** — Tower death (L2), Synthesis (L1), and PvP-kidnap→synthesis (L4, Lv40+ only). All route through two base mechanics. The whole-game master table lives in Layer 4 §5.1.

## Cross-layer interface map

Each layer publishes hooks the next layers plug into. The spine:

```
Layer 0  ── star envelope, derived stats, CP, combat sim, keyword tags, encounterContext flag
   ▲ reads
Layer 1  ── gacha rolls into envelope · promotion lifts it · synthesis transfers grades/skills
   │         · equipment adds flat stats+tags · party feeds SPD/targeting
   ▲ reads (party, synthesis-as-permadeath, Book-of-Reverse-Heaven need)
Layer 2  ── enemies = L0 statlines+keywords · floor power budget = ΣCP · raid bosses drop Book
   │         · win-state floors 90/100
   ▲ reads (floor/mission reward hooks, daily-dungeon & shop content)
Layer 3  ── defines reward AMOUNTS · materials feed L1 promotion/craft · facilities buff L1
   │         · Probability Interference gates unlocks & lifecycle · predatory layer
   ▲ reads (Crack-of-Time unlock @ML20, PI for lifecycle, predatory→whale guilds)
Layer 4  ── opt-in PvP · kidnap→L1 synthesis · sector matchmaking by CP · account lifecycle via PI
```

**Deferral ledger (all paid):** L1→L3 (currency costs, material sourcing, crafting recipes, favorability/sanity scales) ✅ · L2→L3 (reward amounts, shop, daily schedule) ✅ · L2→L4 (tournament matchmaking) ✅ · L3→L4 (PvP unlock, whale guilds, account deletion, Q4 boundary) ✅.

## Global tuning knobs (the first-pass-constants register)

The whole game flexes from a small set of numbers. A balance pass should treat these as the primary dials:

| Knob | Default | Layer | Governs |
|---|---|---|---|
| growth constant `G` | 0.6 | L0 | attribute gain per level per grade |
| XP exponent | 2.2 | L0 | hero grind length |
| defense constant `K` | 50 + 8×lvl | L0 | damage diminishing returns |
| element advantage/disadv | 1.5 / 0.75 | L0 | element wheel swing |
| base `critMult` | 1.5 | L0 | crit damage |
| CP weight vector | §4.1 | L0 | power/matchmaking |
| gacha rates + pity thresholds | §1.2–1.3 | L1 | summon generosity |
| synthesis efficiency `η` | 0.10 (0.25+ @7★) | L1 | synthesis viability |
| floor difficulty | `1.06^f`, +0.15/5-floor step | L2 | tower curve |
| world grade `worldMult` | 1.0–4.0 (C–S) | L2 | per-account difficulty |
| `floorGold` / gem drip | 100×f×worldMult / thin | L3 | economy faucet |
| facility upgrade cost | `base × 1.5^L` | L3 | meta grind |
| master XP exponent | 1.8 | L3 | content pacing |
