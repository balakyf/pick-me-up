## 2. Readability (B10, B48)

- **Ligatures.** Pixelify Sans has `liga` fi/fl/ff/ffi/ffl (checked with fontTools). CSS turns them off on body, form controls, kbd and canvas (`font-variant-ligatures: none; font-feature-settings: 'liga' 0, 'clig' 0, 'calt' 0`). Canvas text (roof signs, speech bubbles, site labels — the only `fillText` paths) goes through `src/ui/canvasText.ts`: `plainText(ctx, font)` sets Chrome's canvas `textRendering = 'optimizeSpeed'` (verified by screenshot to disable the ligatures; `fontKerning='none'` does not) and `breakLigatures()` inserts U+200C between the fused pairs for browsers without canvas `textRendering`.
- **Digits.** Pixelify's numerals misread at every weight (5→S, 2→Z: "2×" read "8×", "555/555" read "SSS/SSS"). Six candidates were rendered side by side at 12–22 px (Pixelify, Silkscreen 400/700, VT323, Tiny5, Micro 5, Jersey 10); **Silkscreen 400** read best and matches the pixel style. `@fontsource/silkscreen` is a dependency; `src/ui/fonts.css` declares a `'PMU Digits'` face with `unicode-range: U+0030-0039` first in `--font` and in the canvas stack, so only digits change. Checked in dev and in a production build (the woff2 is bundled).
- **Favicon.** `src/ui/pixel/favicon.ts` turns the summon crystal sprite (frame 0, without its pedestal) into a crisp SVG of pixel runs → `public/favicon.svg`, linked from `index.html`. `favicon.test.ts` keeps the file equal to the sprite (`UPDATE_FAVICON=1 npx vitest run src/ui/pixel/favicon.test.ts` rewrites it).

## 7. Decisions worth knowing

- `withToasts(store)` is a store wrapper rather than toasts inside each panel, so Advisor.tsx needs no toast code and any later panel can opt in with one line.
- `qol/windowRegistry.ts` is the one place that knows whether a window, dialog or battle is open; later overlays (the Settings window, transitions) can use it instead of DOM queries.
- `ui.css` was only edited in place (font token, body/control ligatures, menu footer, title parade media query); nothing appended. New rules live in `battle.css`, `summon.css`, `tower/tower.css`, `hero/hero.css`, `qol/toast.css`.
- The worktree's `npm install @fontsource/silkscreen` replaced the `node_modules` symlink with a real folder in this worktree only; the main checkout's `node_modules` was not touched. **Run `npm install` in the main checkout after merging** (one new dependency).
